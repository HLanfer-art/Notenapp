📘 Digitales Klassenbuch

Einmalige Einrichtung: Damit deine Einträge auf iPhone, iPad und Mac synchron sind, brauchst du ein eigenes, kostenloses Firebase-Projekt (Google, Spark-Plan, keine Kreditkarte nötig). Deine Daten liegen dann in deinem eigenen, privaten Projekt.

  1. Gehe zu console.firebase.google.com und erstelle ein neues Projekt (Google-Analytics kannst du abwählen).
  2. Klicke im Projekt auf das Web-Symbol </>, um eine Web-App zu registrieren. Du erhältst ein Code-Snippet mit firebaseConfig = {'{'}...{'}'} — kopiere den gesamten Block.
  3. Aktiviere links im Menü Build → Authentication → Sign-in method → E-Mail/Passwort.
  4. Aktiviere Build → Firestore Database → Datenbank erstellen (Region z. B. eur3/Frankfurt für Deutschland), Start im „Produktionsmodus“.
  5. Trage unter Firestore → Regeln Folgendes ein und veröffentliche es: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/entries/{entryId} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
  6. Füge unten den kopierten Code-Block ein und klicke auf „Weiter“.

Diese Angaben sind kein Geheimnis – sie identifizieren nur dein Projekt. Der eigentliche Zugriffsschutz erfolgt über Anmeldung + Firestore-Regeln (siehe Anleitung).
